FunBlox.js

Unofficial Roblox API wrapper for Node.js. Cookie auth and Open Cloud in the same library.

npm GitHub
Warning. This is an unofficial wrapper. Roblox APIs change without notice. Prefer Open Cloud when the endpoint exists. Never share your cookie or API key. Not affiliated with Roblox.

Install

npm i funblox.js

Setup

Legacy (cookie)

const { setCookie } = require("funblox.js");

await setCookie("_|WARNING:-DO-NOT-SHARE-THIS...|_");

Open Cloud (API key)

const { setOpenCloudKey } = require("funblox.js");

setOpenCloudKey(process.env.ROBLOX_CLOUD_KEY);

Dual mode

Pass { useOpenCloud: true } on supported functions to use Open Cloud instead of cookies.

const { getGroup } = require("funblox.js");

const group = await getGroup(123456, { useOpenCloud: true });

Open Cloud direct

Use opencloud for endpoints that don't have a legacy twin.

Universes & messaging

const { opencloud } = require("funblox.js");

const universe = await opencloud.getUniverse(123456789);
await opencloud.publishMessage(123456789, "announcements", "Hello!");

Data stores

const stores = await opencloud.listDataStores(123456789);
const entry = await opencloud.getDataStoreEntry(123456789, "PlayerData", "user_156");
await opencloud.setDataStoreEntry(123456789, "PlayerData", "user_156", { coins: 100 });

Group roles & memberships

const roles = await opencloud.listGroupRoles(123456);
const members = await opencloud.listGroupMemberships(123456);

await opencloud.assignRole(123456, "membership-id", 111222);
await opencloud.unassignRole(123456, "membership-id", 111222);
await opencloud.setRank(123456, 987654, 111222);

Join requests

const requests = await opencloud.listJoinRequests(123456);
await opencloud.acceptJoinRequest(123456, 987654);
await opencloud.declineJoinRequest(123456, 987654);

Generic request

const { openCloudRequest } = require("funblox.js");

const data = await openCloudRequest("/cloud/v2/groups/123456");
