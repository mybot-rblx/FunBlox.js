FunBlox.js

Unofficial Node.js wrapper for the Roblox API. Cookie auth and Open Cloud in the same library. Each function below lists what it does, what it returns, and what it rejects.

npm GitHub MIT

Install

npm i funblox.js

CommonJS and ESM both work. Types ship with the package.

Roblox changes endpoints without notice. Prefer Open Cloud when it exists. Never share a .ROBLOSECURITY cookie or an API key. Not affiliated with Roblox.

Auth

setCookie(cookie) → Promise
cookie

Stores a .ROBLOSECURITY cookie and returns the logged-in user. Required for legacy writes (rank, wall deletes).

Parameters
NameTypeDescription
cookiestringFull Roblox security cookie, including the warning prefix.
Returns

{ id, name, displayName }

Rejects
  • Error: You are not logged in! — cookie invalid or expired.
  • HTTPError 401 — Roblox rejected the session.
const { setCookie } = require("funblox.js");
const me = await setCookie(process.env.ROBLOX_COOKIE);
setOpenCloudKey(apiKey, accessToken?) → OpenCloudClient
open cloud

Sets the API key (and optional OAuth token) used by every Open Cloud call.

Parameters
NameTypeDescription
apiKeystringSent as x-api-key.
accessTokenstring?Optional OAuth bearer token.
Returns

The default OpenCloudClient (chainable).

Rejects

Does not call the network. Later requests reject if the key is missing or lacks scope.

const { setOpenCloudKey } = require("funblox.js");
setOpenCloudKey(process.env.ROBLOX_CLOUD_KEY);

Users

getUser(identifier, options?) → Promise
dualpublic

Looks up a user by username or id. Legacy mode also tries friends, followers and the avatar. If those social endpoints 401, counts come back as 0 instead of failing the whole call.

Parameters
NameTypeDescription
identifiernumber | stringUser id or username.
options.useOpenCloudboolean?Use GET /cloud/v2/users/{id}.
Returns (legacy)
{
  id, username, displayName, description, created,
  avatar_url,
  friends:   { count, ids },
  followers: { count, ids },
  following: { count, ids }
}
Returns (Open Cloud)

Roblox user resource: path, id, name, displayName, createTime…

Rejects
  • TypeError: Identifier must be a number or a string
  • HTTPError 404 — user does not exist.
  • Open Cloud request failed [401|403] — bad or under-scoped key.
const user = await getUser("builderman");
const byId = await getUser(156, { useOpenCloud: true });

Groups

getGroup(identifier, options?) → Promise
dualpublic

Group profile by numeric id, numeric string, or name. Legacy mode also loads roles, shout and the icon.

Parameters
NameTypeDescription
identifiernumber | stringId or exact group name.
options.useOpenCloudboolean?Hit /cloud/v2/groups/{id}.
Returns (legacy)
{
  id, name, description, membercount, thumbnail,
  owner: { userId, username, displayName },
  shout: { content, created, author } | null,
  roles: [{ id, name, membercount }]
}
Rejects
  • Error: Group not found — name search had no match.
  • TypeError: Invalid group identifier
  • HTTPError 404 — id does not exist.
  • Open Cloud request failed [401|403|404]
const g = await getGroup(2700627);
const byName = await getGroup("Roblox");
const cloud = await getGroup(2700627, { useOpenCloud: true });
