What this is

FunBlox.js is an unofficial Node.js wrapper for the Roblox API. You can talk to Roblox with the old cookie method, with Open Cloud (API key), or both at the same time.

Warning. Roblox APIs change without notice. Prefer Open Cloud when the endpoint exists. Never share your cookie or API key. Not affiliated with Roblox. 
npm i funblox.js

Catalog

UsersProfile, rank, thumbnails, bundles GroupsInfo, ranks, wall, promote/demote GamesPlace info, votes, universe id CatalogCategories and favorites Open CloudMessaging, data stores, join requests

Auth

Cookie legacy

Logs the library in with a .ROBLOSECURITY cookie. Needed for legacy endpoints that require you to be logged in (rank changes, wall deletes, etc.).

const { setCookie } = require("funblox.js");
await setCookie("_|WARNING:-DO-NOT-SHARE-THIS...|_");

Open Cloud recommended

Sets the API key used by Open Cloud. More stable than cookies. Create the key in the Creator Dashboard.

const { setOpenCloudKey } = require("funblox.js");
setOpenCloudKey(process.env.ROBLOX_CLOUD_KEY);

Dual mode

On supported functions, pass { useOpenCloud: true } to hit Open Cloud instead of the cookie API.

const group = await getGroup(123456, { useOpenCloud: true });

Users

getUser dual

Gets a user's public profile: id, username, display name, description, created date, and (legacy) friend/follower counts. Accepts a username or a user id.

const { getUser } = require("funblox.js");

const user = await getUser("builderman");
const byId = await getUser(156);
const cloud = await getUser(156, { useOpenCloud: true });

getUserRank

Gets a user's rank and role inside a specific group. Useful to check permissions before promoting or paying out.

const { getUserRank } = require("funblox.js");
const rank = await getUserRank(123456, 987654); // groupId, userId

getGroups

Lists the groups a user is in, with their role in each one.

const { getGroups } = require("funblox.js");
const groups = await getGroups(156);

getPlayerThumbnail

Returns the URL of a user's avatar thumbnail. Handy for bots, dashboards, or embeds.

const { getPlayerThumbnail } = require("funblox.js");
const thumb = await getPlayerThumbnail(156);

getUserBundles

Lists the bundles (avatar packages) a user owns.

const { getUserBundles } = require("funblox.js");
const bundles = await getUserBundles(156);

getUserFavoriteGames

Gets the games a user has favorited. If Roblox blocks the endpoint, it returns an empty array instead of throwing.

const { getUserFavoriteGames } = require("funblox.js");
const games = await getUserFavoriteGames(156, 10);

Groups

getGroup dual

Gets group info: name, description, owner, member count, roles, shout, and thumbnail. Accepts a numeric id, a string id, or a group name.

const { getGroup } = require("funblox.js");

const byId = await getGroup(2700627);
const byName = await getGroup("Target Store");
const cloud = await getGroup(2700627, { useOpenCloud: true });

getGroupGames

Lists the games (experiences) owned by a group.

const { getGroupGames } = require("funblox.js");
const games = await getGroupGames(2700627);

getGroupWall

Gets the group's wall posts. Useful for moderation bots that scan or clean the wall.

const { getGroupWall } = require("funblox.js");
const wall = await getGroupWall(2700627);

setRank dual

Sets a user's role in a group to a specific rank id. Requires cookie (legacy) or an Open Cloud key with group permissions.

const { setRank } = require("funblox.js");

await setRank(123456, 987654, 111222);                          // cookie
await setRank(123456, 987654, 111222, { useOpenCloud: true });  // Open Cloud

promote / demote

Moves a user one rank up or one rank down in the group. Easier than looking up role ids when you just want the next/previous rank.

const { promote, demote } = require("funblox.js");

await promote(123456, 987654);
await demote(123456, 987654);

deletePost

Deletes a single wall post by its id. Needs a cookie with permission to manage the wall.

const { deletePost } = require("funblox.js");
await deletePost(123456, 555); // groupId, postId

deletePostBySpecificUser

Deletes wall posts made by a specific user. Useful for cleaning spam from one account.

const { deletePostBySpecificUser } = require("funblox.js");
await deletePostBySpecificUser(123456, 987654);

Games

getPlaceInfo

Gets info about a place: name, description, creator, visits, and related data. Use a place id (the number in the game URL).

const { getPlaceInfo } = require("funblox.js");
const place = await getPlaceInfo(1818);

getGameVotes

Gets the like/dislike (upvote/downvote) counts for a game.

const { getGameVotes } = require("funblox.js");
const votes = await getGameVotes(1818);

getUniverseId

Converts a place id into a universe id. Open Cloud and many modern APIs need the universe id, not the place id.

const { getUniverseId } = require("funblox.js");
const universeId = await getUniverseId(1818);

Catalog

getCategories

Lists catalog categories (hats, gear, etc.). Useful if you're building a catalog browser.

const { getCategories } = require("funblox.js");
const categories = await getCategories();

getFavoritesOfItem

Gets how many people favorited a catalog item (asset).

const { getFavoritesOfItem } = require("funblox.js");
const favs = await getFavoritesOfItem(1028595);

getFavoritesOfBundle

Gets how many people favorited a bundle.

const { getFavoritesOfBundle } = require("funblox.js");
const favs = await getFavoritesOfBundle(192);

Open Cloud

Use opencloud for endpoints that don't have a cookie equivalent, or when you want to be explicit.

getUniverse

Gets universe (experience) details from Open Cloud.

const { opencloud } = require("funblox.js");
const universe = await opencloud.getUniverse(123456789);

publishMessage

Publishes a message to a Messaging Service topic. Your game servers can subscribe and react (announcements, live events, etc.).

await opencloud.publishMessage(123456789, "announcements", "Hello!");

Data stores

Read and write DataStore entries from outside the game. Needs a key with data store permissions.

const stores = await opencloud.listDataStores(123456789);
const entry = await opencloud.getDataStoreEntry(123456789, "PlayerData", "user_156");
await opencloud.setDataStoreEntry(123456789, "PlayerData", "user_156", { coins: 100 });

Roles & memberships

List roles and members, then assign or remove a role. Open Cloud uses membership ids for assign/unassign.

const roles = await opencloud.listGroupRoles(123456);
const members = await opencloud.listGroupMemberships(123456);

await opencloud.assignRole(123456, "membership-id", 111222);
await opencloud.unassignRole(123456, "membership-id", 111222);
await opencloud.setRank(123456, 987654, 111222);

getGroupShout

Gets the current group shout (the status message at the top of the group page).

const shout = await opencloud.getGroupShout(123456);

Join requests

List, accept, or decline pending join requests. Useful for group bots that auto-accept or review applications.

const requests = await opencloud.listJoinRequests(123456);
await opencloud.acceptJoinRequest(123456, 987654);
await opencloud.declineJoinRequest(123456, 987654);

openCloudRequest

Generic request to any Open Cloud path. Use this when a helper doesn't exist yet.

const { openCloudRequest } = require("funblox.js");
const data = await openCloudRequest("/cloud/v2/groups/123456");
